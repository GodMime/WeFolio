分享页色系适配 + 作品组件间距与显隐开关

本版收敛范围：除作品组件外，所有组件视觉完全维持项目现状，仅把既有强调色替换为主题色； WORK_GRID / WORK_LIST 做间距微调；WORK_GRID / WORK_LIST / SINGLE_WORK 统一提供作品标题、作品说明两个显隐开关。 色系通过新增作品集级配置 theme 选择，向前兼容。

组件维持现状布局、字号、间距、圆角、进度条、月历、表单等一律不动；唯一变化是"强调色"从硬编码色值改为主题变量。
向前兼容theme 与两个显隐开关均为可选新增键，缺省值 = 当前线上渲染效果；旧 schema_json 零迁移，旧版小程序忽略新字段不报错。
作品组件微调仅 WORK_GRID / WORK_LIST 调整卡片间距；WORK_GRID / WORK_LIST / SINGLE_WORK 均提供 showTitle / showDescription 开关，缺省值统一为 true / false。
配置色优先tags[].color、档位 slot color、divider color 等用户可配色一律保留，不被主题色覆盖。

新增配置：页面色系 theme

schema_json 根级（与 share、components 平级）新增可选键 theme，白名单 GOLD / ROSE / BLUE / PINE。后端 Validator 校验白名单、非法值回落 GOLD；RenderService 透传； 前端 normalize 缺省 GOLD，页面根节点挂 theme-xxx class，组件内既有强调色改为主题变量。 旧作品集无此键 → 默认 GOLD；旧版小程序忽略此字段 → 按原硬编码色渲染（注意：此时旧小程序看到的一定是 GOLD 色系的硬编码值，所以 GOLD 必须与现状视觉一致或最接近，见下表说明）。
