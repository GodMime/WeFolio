12 点击图标 Logo 设计超链接组件点击图标 · 图形含义 / 尺寸 / 深浅底适配 / 浅色与暗色双主题 / 设计规范 / 透明 GIF 点击动效
点按手型 · 点击图标
拟人点按手型：食指伸直、拇指外展、三指弯曲收拢，整体微倾 12° 营造“伸手去点”的动感；指尖上方三道点击光芒线，直观表达“点按触发”。延续旅行风黑白灰体系：#212529 圆形徽标 + 白色图形；悬浮于图片上时叠加 1.5px 半透明白描边与外圈脉冲环，保证深色 / 浅色 / 复杂图片上均可识别。
主徽标 · 使用尺寸（44 / 38 / 30 / 24px）

38 图下方

悬浮于深色图
深色图上徽标不沉没
图形构成（48px 网格）
动效：下压回弹 + 触控扩散环 + 点击光芒
设计规范
网格48 × 48px 绘制，2.4px 线稿，圆角端点与连接，四周留 6px 安全区。
构成拟人点按手型（食指伸直、拇指外展、三指弯曲收拢）整体微倾 12° + 指尖三道点击光芒线，表达“点按、有回应”。
徽标圆形底色 #212529，图形纯白，投影 0 6px 16px rgba(33,37,41,.28)。
悬浮态1.5px rgba(255,255,255,.9) 描边 + 外扩 7px 脉冲环 rgba(33,37,41,.28)，定位图片右下角（right/bottom 14px）。
图下方态徽标 38px，居中一行，无描边与脉冲环。
最小尺寸24px；低于 24px 时省略光芒线，仅保留点按手型。
双主题浅色页：#212529 徽标 + 白色图形（CDN click-tap-icon.gif）；暗色页：#ffffff 反白徽标 + 深色图形（CDN click-tap-icon-dark.gif），动效一致。
动效交付为透明 GIF（240 × 240，约 1.4s 循环）：点按时手型下压回弹，指尖扩散触控环并闪现点击光芒，可直接叠加在任意图片上。
