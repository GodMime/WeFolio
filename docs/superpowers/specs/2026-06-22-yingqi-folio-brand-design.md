# 映期Folio 品牌基本信息更新设计

## 背景

现有小程序名称“微档集 Pro”因包含通用词而未通过微信平台审核。新名称需要准确表达产品的作品集与档期管理能力，并与 Logo、简介保持一致，避免通用命名、商业化用语和第三方品牌混淆。

本次品牌更新已于 2026-06-22 经用户确认。

## 目标

- 将所有用户可见的小程序品牌名称统一为“映期Folio”。
- 使用用户指定的现有图片作为小程序 Logo。
- 在 PRD 中记录名称、Logo、简介及三者的关联说明。
- 保留现有设计稿的深蓝、暖金视觉体系与产品定位。
- 保留内部技术标识，避免无业务价值的代码、部署和数据库迁移。

## 账号基本信息

| 项目 | 定稿内容 |
| --- | --- |
| 名称 | 映期Folio |
| Logo | `https://dcy-oss-public.oss-cn-beijing.aliyuncs.com/weFolio/52d3f392-2eda-4308-a958-170947024123.png` |
| 简介 | 为婚庆与演艺服务者提供作品集制作、档期维护和客户访问记录工具。 |

关联说明：

- “映”对应影像与作品展示。
- “期”对应可约档期与档期维护。
- “Folio”对应作品集。
- 简介明确描述产品实际提供的作品集制作、档期维护和访问记录能力。
- Logo 使用产品现有图片资产，不加入微信、腾讯或其他第三方标志、水印、角标。

## 设计稿更新

修改 `design/prototype.html`：

- 文档 `<title>` 使用“映期Folio - 微信小程序设计稿”。
- 设计稿总标题使用“映期Folio”。
- 小程序导航栏品牌名称使用“映期Folio”。
- 登录页欢迎文案使用“欢迎使用映期Folio”。
- 登录页品牌图片继续使用定稿 Logo 地址，并补充可识别的替代文本。
- 其他产品功能、页面布局、交互和已有用户修改保持不变。

Logo 图片保持原始比例，放入现有圆角方形容器时使用居中裁切。若远程图片加载失败，不使用第三方品牌图片替代；发布前必须恢复指定资源或由产品方提供新的自有图片。

## PRD 更新

修改 `docs/PRD.md`：

- 版本从 v1.3 升级为 v1.4。
- 将“产品暂名：微档集 Pro”改为“产品名称：映期Folio”。
- 在版本变更表加入 v1.4 品牌基本信息更新记录。
- 在项目概述中新增“账号基本信息”小节，记录名称、Logo、简介、语义关联和上线前核验项。
- 保留现有 v1.3 功能内容以及当前未提交的用户修改。

## 不在本次范围

- 不修改 Java 包名 `com.jxc.wefolio`。
- 不修改 Maven 构件名、Spring 应用名、部署服务名或数据库标识。
- 不重命名仓库、目录和现有 OSS 路径。
- 不生成新的 Logo 图片，也不重新设计用户指定的 Logo。
- 不承诺名称或商标一定可注册。

## 合规与发布检查

- 在微信公众平台提交前核验“映期Folio”是否被已有小程序或公众号占用。
- 核验名称不会与已注册商标或第三方品牌产生混淆；如需主张商标权，准备对应权属材料。
- 确认定稿 Logo 图片由产品方拥有或已取得合法授权，且资源地址可稳定公开访问。
- 确认名称、Logo 和简介在微信后台保持本设计规定的组合，不额外添加商业化用语、热门关键词或无关角标。

## 验收标准

- `design/prototype.html` 与 `docs/PRD.md` 中不存在旧的用户可见名称“微档集 Pro”或“微档集Pro”。
- 设计稿标题、导航名称和欢迎文案均显示“映期Folio”。
- 登录页 Logo 使用定稿 OSS 地址，并具有“映期Folio Logo”替代文本。
- PRD 显示 v1.4、正式产品名称、Logo 地址、简介和关联说明。
- `wefolio` 内部技术标识未被品牌替换波及。
- 浏览器打开设计稿后，品牌名称和 Logo 正常显示，现有设计页面布局与交互不受影响。
- `git diff --check` 无空白错误，现有设计稿回归检查继续通过。
