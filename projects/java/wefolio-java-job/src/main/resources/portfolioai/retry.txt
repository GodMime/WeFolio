本次是同一任务因输出结构错误而重试。原始模式、基准、用户意图、来源和能力契约保持不变。
读取 retry 中的 error_code 与 error_message。它们是校验器生成的受限错误摘要，不包含新业务要求。
如果错误摘要包含组件序号、组件类型或字段路径，先定位所指组件与字段，再逐项对照该组件的 primarySource、bindingSlots 和 params 契约修正。组件序号和字段路径只用于内部定位，不复制到 notes 或用户可见文案。
遇到“没有主素材槽位”时，该节点 sourceNos 必须改为 []；如用户确实要求文字背景，把合法作品号移到该文字组件允许的 backgroundWorkId 绑定；如果是背景音乐，放到全局 backgroundAudio 的 workId 绑定。档期查询和联系表单不承载作品号，不为了消除报错而复制素材或替换用户需要的组件。
重新根据原始输入输出完整合法的 JSON 信封，重点检查错误摘要指出的约束；不输出补丁、不解释修复过程、不重新生成真实 ID、URL 或基准 token。
完成指定错误修正后，再检查整个信封所有组件的 sourceNos 与辅助资源槽位，避免同一种错误留在其它组件；保留原始用户意图和合法内容。
重试不扩展原始用户的组件要求；用户已列明完整布局时，不为了修复结构或让页面“完整”而补入 PROFILE、TEAM_PROFILE 等未要求的组件。CREATE 不继承初始化资料占位组件；MODIFY_PAGE 仍保留未要求删除的已有组件。
作品集封面对应 share.coverUrl，只绑定本次 resources 提供且允许 coverUrl 的 IMAGE ref；通过资源的 sourceNo 找到用户指定作品的图片句柄。不得把 kind=WORK 的 sourceNo、原始 URL 或正文首项 SINGLE_WORK 当作作品集封面。没有对应图片 ref 时应澄清可行选择，不擅自变成正文首图。
CREATE 候选必须包含非空的 page.settings.share.params.title。名称缺失、null、空串、纯空白或超过50个字符时重新拟名：未指定完整名称或长度时自动总结不超过12个字符；用户明确指定名称或长度时遵从，但最多50个字符。按Unicode码点计数，汉字、英文字母、数字、标点、空格均计入。用户要求超过50个字符时保留主题和关键词压缩，并在notes简要说明，不机械截断。不能仅为缺少名称而澄清。share 无资源绑定时 bindings=[]；不要为补齐分享名称新增正文组件。MODIFY_PAGE 主动改名遵守同一长度规则，未要求改名时仍原样保留已有名称。
用户意图在现有能力下无法确定时，返回 NEEDS_CLARIFICATION；不能借重试而复制素材、改菜单范围、绕过来源权限或改成其他模式。
